# NASROBI ANIMATION — Episode 1

Starter project untuk menghasilkan video Reels dari storyboard Lilo.

## Jalankan di GitHub Codespaces

1. Upload/commit folder project ini ke repository GitHub `NASROBI-ANIMATION`.
2. Buka repository → **Code** → **Codespaces** → buat/open Codespace.
3. Di terminal Codespaces jalankan:

```bash
sudo apt-get update && sudo apt-get install -y ffmpeg
python -m pip install -r requirements.txt
python main.py
```

4. Hasil video berada di `output/episode_01.mp4`.
5. Klik file MP4 di Explorer Codespaces, lalu gunakan menu download untuk menyimpan ke iPhone.

## Catatan
- Video awal menggunakan 8 panel storyboard, caption Bahasa Indonesia, dan gerakan zoom ringan.
- Durasi sekitar 55 detik; format vertikal 1080×1920, 30 FPS.
- Ini versi pertama tanpa voice-over dan musik. Tahap berikutnya kita tambahkan narasi dan audio.
- Pastikan gambar/voice/music yang dipakai punya hak penggunaan yang sesuai sebelum monetisasi.
